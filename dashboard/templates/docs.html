DEVELOPER QUICKSTART & INTEGRATION

Drop-in Integration in 2 Lines of Code

HeimdallCache adheres to standard OpenAI and Bifrost gateway protocol specifications. No SDK rewrites required. 

from openai import OpenAI

# 1. Point client to HeimdallCache Gateway proxy
client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="none"  # Heimdall handles upstream keys
)

# 2. Make chat completion as normal
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "What is the monthly pricing for Twitter X Premium?"}]
)

# 3. Access verified content
print(response.choices[0].message.content)

import OpenAI from 'openai';

// Point client to Heimdall proxy
const openai = new OpenAI({
  baseURL: 'http://localhost:8000/v1',
  apiKey: 'none'
});

async function main() {
  const completion = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [{ role: 'user', content: 'What is the monthly pricing for Twitter X Premium?' }],
  });

  console.log(completion.choices[0].message.content);
}

main();

# bifrost.yaml configuration
gateways:
  - name: "heimdall-living-proxy"
    port: 8080
    plugins:
      - name: "heimdall_semantic_cache"
        endpoint: "http://localhost:8000/v1/chat/completions"
        invalidation_strategy: "tavily_delta_probe"
        similarity_threshold: 0.85
        freshness_threshold: 70

Heimdall Telemetry Response Headers

Every response returned by Heimdall contains diagnostic inspection headers:

Header Possible Values Description
X-Heimdall-Cache HIT_VERIFIED, STALE_INVALIDATED, CACHE_MISS Result of vector lookup and Tavily drift verification.
X-Heimdall-Freshness-Score 0.0% to 100.0% Current factual accuracy score computed against live web ground truth.
X-Heimdall-Latency-MS e.g. 2.4 ms End-to-end proxy processing latency.
