Drop-in Integration in 2 Lines of Code

HeimdallCache adheres to standard OpenAI and Bifrost gateway protocol specifications. No SDK rewrites required. 

from openai import OpenAI

# 1. Point client to HeimdallCache Gateway proxy
client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="none"  # Heimdall handles upstream keys
)

# 2. Make chat completion as normal
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "What is the monthly pricing for Twitter X Premium?"}]
)

# 3. Access verified content
print(response.choices[0].message.content)
# If vector decayed: Heimdall launched async Tavily probe, evicted stale price ($8),
# and returned verified ground truth ($3 / $8 / $16) with 0 zombie hallucination.
import OpenAI from 'openai';

// 1. Point official OpenAI SDK to Heimdall Living Proxy
const openai = new OpenAI({
  baseURL: 'http://localhost:8000/v1',
  apiKey: 'none', // Handled by proxy
});

async function main() {
  const completion = await openai.chat.completions.create({
    messages: [{ role: 'user', content: 'What is the current time complexity of QuickSort?' }],
    model: 'gpt-4o',
  });

  console.log(completion.choices[0].message.content);
}

main();

      - UPSTREAM_PROXY_URL=http://heimdall:8000/v1

  heimdall:
    build: .

      - "8000:8000"

      - TAVILY_API_KEY=${TAVILY_API_KEY}

Core REST Endpoints

Conforms to OpenAI specification plus Heimdall living introspection endpoints.

POST /v1/chat/completions
OpenAI compatible chat completions with living vector cache
GET /api/cache/entries
Inspect living vector store, volatility tags, and half-lives
POST /api/cache/probe/{entry_id}
Manually trigger an asynchronous Tavily delta-probe
DELETE /api/cache/entries/{entry_id}
Explicitly evict a poisoned or decaying vector
